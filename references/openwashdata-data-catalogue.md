# openwashdata: Data Catalogue

Source: https://openwashdata.org/pages/gallery/data/
Captured: 2026-06-24

## Overview

The catalogue holds **51 published datasets** covering water, sanitation, and hygiene (WASH) topics across multiple regions.

## Geographic coverage

- Africa-focused: Malawi (16 datasets), Ghana (3), Uganda (2), Kenya (2), Côte d'Ivoire, Haiti, Brazil.
- Global datasets: 15 covering international topics.

## Data types

- Infrastructure surveys (water points, boreholes, latrines, handpumps).
- Household-level assessments (sanitation practices, water costs, consumer satisfaction).
- Spatial / geospatial data (suitability analyses, hydrogeological mapping).
- Epidemic tracking (cholera data).
- Laboratory analyses (water quality testing).
- Engineering experiments (faecal sludge treatment).
- Institutional data (university rankings, development indicators, humanitarian organisations).

## Format and accessibility

> Each data set comes with its own website and rich documentation to increase reusability.

Data follows an R package workflow, with individual GitHub repositories providing documentation and access to the underlying datasets. The dedicated website and documentation for each dataset are designed to facilitate reuse across research and implementation contexts.
